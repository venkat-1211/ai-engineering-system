# Prompt 03 — Controlled CD & Environment Promotion

Inspect the current release process and design a controlled deployment workflow. Build once and promote the exact immutable artifact digest through environments. Define environment protections, identity scopes, approvals, preconditions, health checks, abort thresholds, concurrency, deployment strategy, and audit evidence.

Production and destructive actions require explicit human approval. Do not execute a deployment, change infrastructure, read or print secret values, or bypass protections. Clearly separate design recommendations from implemented and verified behavior.
