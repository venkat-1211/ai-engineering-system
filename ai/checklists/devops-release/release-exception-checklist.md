# Release Exception Checklist

- [ ] Exception is permitted under applicable policy.
- [ ] Named accountable human owner.
- [ ] Exact control, service, environment, and scope identified.
- [ ] Business/technical rationale documented.
- [ ] Risk and impact assessed.
- [ ] Compensating controls defined.
- [ ] Approval by authorized human recorded.
- [ ] Expiry and review date set.
- [ ] Monitoring and revocation conditions defined.
- [ ] Follow-up remediation tracked.

No AI agent may approve its own exception or bypass a required production approval.
Status: `Passed` / `Failed` / `Not run` / `Blocked` / `Requires human approval`
