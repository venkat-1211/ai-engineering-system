# Production Operations Standards

This directory defines operational practices for systems from deployment through retirement.

## Standards
- `docs/production-operations/PRODUCTION_OPERATING_MODEL.md` — service ownership, operational lifecycle and environments.
- `docs/production-operations/OBSERVABILITY_STANDARD.md` — logs, metrics, traces, dashboards and alert quality.
- `docs/production-operations/SERVICE_LEVEL_OBJECTIVES.md` — SLIs, SLOs, SLAs and error budgets.
- `docs/production-operations/INCIDENT_MANAGEMENT.md` — incident detection, command, communication and closure.
- `docs/production-operations/PROBLEM_MANAGEMENT_AND_POSTMORTEMS.md` — root-cause analysis and corrective actions.
- `docs/production-operations/BACKUP_AND_RESTORE.md` — backup design, restore validation and retention.
- `docs/production-operations/DISASTER_RECOVERY_AND_CONTINUITY.md` — recovery strategies, RTO/RPO and continuity.
- `docs/production-operations/CAPACITY_AND_PERFORMANCE_OPERATIONS.md` — capacity, saturation and scaling.
- `docs/production-operations/OPERATIONAL_SECURITY.md` — access, secrets, patching and security events.
- `docs/production-operations/RUNBOOKS_AND_CHANGE_OPERATIONS.md` — runbooks, change controls and rollback.
- `docs/production-operations/OPERATIONAL_METRICS_AND_REVIEW.md` — operational scorecards and review cadence.

## Applicability
Select controls based on architecture, data sensitivity, availability needs, threat model, legal obligations and operational maturity. Record decisions and gaps. Do not assume every project needs 24/7 on-call, multi-region failover or formal SLOs.
