# HTML, CSS, Bootstrap and Responsive UI Standard

- Verify Bootstrap and design-system versions before using version-specific classes or APIs.
- Use semantic HTML, logical headings, native controls and associated labels. Use tables for tabular data.
- Preserve existing design tokens and component conventions unless redesign is requested.
- Prefer flexible, mobile-first layouts. Test narrow mobile, tablet, laptop and desktop viewports.
- Prevent horizontal overflow, clipped controls, overlap, unreadable text and unusable touch targets.
- Do not fix layout problems by hiding required content or reducing usability.
- Use Grid/Flexbox appropriately, scope styles, avoid broad selectors and unexplained `!important`.
- Avoid conflicting duplicate CSS and unexplained magic numbers. Keep focus indicators visible.
- Do not mix Bootstrap major-version markup. Reuse the existing UI framework; avoid adding another without approval.
- Check navigation, forms, tables, modals, cards, sidebars, images and dense data-entry areas independently.
- Ensure keyboard access, contrast, alt text, zoom/reflow and reduced-motion support.
- Verify loading, empty, validation, disabled and error states. Claim visual verification only if actual browser/viewport checks were performed.
