# 04 Design Adversarial Tests

Use the actual architecture and threat model to design a risk-based adversarial test suite covering prompt injection, sensitive-data disclosure, cross-tenant leakage, unauthorized tools, privilege escalation, malformed arguments, unsafe output, resource abuse, and safe failure as applicable. Use synthetic fixtures and authorized isolated environments. Provide test IDs, threat mapping, preconditions, steps, deterministic expected results, evidence, cleanup, and regression mapping.
