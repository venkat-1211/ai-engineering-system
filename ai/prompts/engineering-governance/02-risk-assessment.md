# Prompt 02 — Risk Assessment

Perform an evidence-based risk assessment for the specified project or change.

## Instructions
- Inspect relevant repository and project documentation within the authorized scope.
- Identify assets, data, users, dependencies, trust boundaries, failure modes, threats, and AI-specific risks where applicable.
- Use the project's defined likelihood and impact scales. If none exist, propose explicit scales and label them provisional.
- Record existing controls separately from controls merely planned.
- Identify residual risk, uncertainty, treatment options, owners, and reassessment triggers.
- Do not accept risk or approve treatments on behalf of a human.

## Output
Use `ai/templates/engineering-governance/RISK_REGISTER.md` as the record structure. Cite exact file paths or evidence references. Mark unavailable evidence as unavailable. Do not modify files unless separately authorized.
