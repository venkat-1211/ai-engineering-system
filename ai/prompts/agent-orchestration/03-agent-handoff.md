# Prompt 03 — Prepare an Agent Handoff

Prepare a precise handoff for the next accountable agent using `ai/templates/agent-orchestration/HANDOFF_REPORT.md`.

Include:
- task ID, sender, receiver, status;
- objective and acceptance criteria;
- authoritative repository instructions and relevant files;
- scope, exclusions, permissions, and dependencies;
- actual files changed;
- decisions and rationale;
- commands actually executed and their results;
- test evidence using the five approved statuses;
- observed facts, inferences, assumptions, and unknowns;
- unresolved defects, risks, and blockers;
- next action and approval requirements.

Do not include secrets, credentials, unnecessary personal data, or unsupported claims. Do not claim tests or commands ran unless they actually did. If critical context is missing, identify it rather than guessing.
