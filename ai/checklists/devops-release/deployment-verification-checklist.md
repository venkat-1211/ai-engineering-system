# Deployment Verification Checklist

- [ ] Correct environment and target verified.
- [ ] Running version, commit, and artifact digest verified.
- [ ] Health/readiness checks pass.
- [ ] Critical smoke tests pass.
- [ ] Migrations/workers/queues are healthy.
- [ ] Error rate and latency within thresholds.
- [ ] Logs/traces show no unexpected regression.
- [ ] Access boundaries and security controls remain valid.
- [ ] Traffic/rollout state is as intended.
- [ ] Human acceptance recorded.

Status: `Passed` / `Failed` / `Not run` / `Blocked` / `Requires human approval`
