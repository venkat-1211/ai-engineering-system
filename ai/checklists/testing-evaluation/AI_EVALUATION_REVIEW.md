# AI-Generated Code, Test and Agent Evaluation Checklist

- [ ] Generated output treated as an untrusted proposal
- [ ] Current instructions, versions, and repository APIs verified
- [ ] Code independently reviewed against acceptance criteria
- [ ] Generated tests have meaningful assertions and adequate edge cases
- [ ] Test oracles and expected values independently validated
- [ ] Prompt/model/tool/dataset versions recorded for evaluations
- [ ] Evaluation cases include representative and adversarial scenarios
- [ ] Scoring rubric and evaluator limitations are disclosed
- [ ] No fabricated test output, sources, approvals, or metrics
- [ ] Secrets and personal data are excluded or properly protected
