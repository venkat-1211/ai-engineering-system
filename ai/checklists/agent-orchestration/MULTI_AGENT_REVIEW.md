# Multi-Agent Integration and Review Checklist

- [ ] Consolidated output matches the approved requirements.
- [ ] Each task has a clear completion status and evidence.
- [ ] All agent changes are inspected in the actual repository.
- [ ] No unassigned or unrelated files were changed.
- [ ] No concurrent edits were silently overwritten.
- [ ] Shared interfaces and assumptions are consistent.
- [ ] Conflicting decisions are resolved and recorded.
- [ ] Applicable technology standards were followed.
- [ ] Security and privacy review is complete where required.
- [ ] Required tests were actually executed and results recorded.
- [ ] Independent review is complete for high-risk work.
- [ ] Human approvals are recorded before gated actions.
- [ ] Remaining risks, `Not run`, and `Blocked` items are disclosed.
- [ ] Final report does not overstate completion.
