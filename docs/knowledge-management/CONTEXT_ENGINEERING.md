# Context Engineering

Goal: supply the smallest sufficient, current, authorized context.

## Discovery
1. Read governing and relevant local instructions.
2. Identify objective, acceptance criteria, scope, risk, and prohibited actions.
3. Inspect current repository state and implementation.
4. Locate relevant requirements, architecture, APIs, data models, tests, deployment, decisions, and operations records.
5. Check authorization, project, version, date, status, owner, and freshness.
6. Report conflicts and missing context; do not silently merge.
7. Prepare `ai/templates/knowledge-management/CONTEXT_BRIEF.md` with stable source references.

Prioritize authority, directness, freshness, applicability, and relevance. Exclude unrelated history, secrets, duplicates, and unauthorized material. Summaries do not replace source inspection.
