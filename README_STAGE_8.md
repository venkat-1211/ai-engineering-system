# Stage 8 — AI Engineering Intelligence, Knowledge Management & Continuous Learning

## Objective
Create a governed, evidence-based way to discover, capture, retrieve, validate, maintain, and reuse engineering knowledge across tasks and agents.

## Contents
- `AGENTS_STAGE_8_ADDENDUM.md`: proposed additions to the existing root instructions.
- `docs/knowledge-management/`: knowledge model, context, retrieval, evidence, lifecycle, decisions, learning, reuse, isolation, continuity, governance.
- `ai/templates/knowledge-management/`: reusable knowledge, context, source, decision, lesson, review, and handoff records.
- `ai/checklists/knowledge-management/`: quality, context, reuse, and lifecycle checklists.
- `ai/prompts/knowledge-management/`: six controlled discovery, capture, retrieval, review, retrospective, and audit prompts.

## Integration
1. Extract into the existing repository root; preserve existing files.
2. Review the addendum and merge it into the current root `AGENTS.md`; never replace the root file with the addendum.
3. Preserve Stages 1–7, existing section order, and instruction precedence.
4. Run the read-only governance/integration audit, correct findings, then run the final pre-commit audit.
5. Commit only after human review and approval.

## Non-goals
No database, vector store, embedding model, search vendor, knowledge graph, or agent framework is mandated. This stage does not authorize automatic approval, publication, or production changes.

## Core principles
Current instructions and current repository evidence outrank historical notes. Retrieval relevance is not truth. Preserve provenance, trust labels, scope, freshness, and limitations. Enforce authorization before retrieval. Default to project-confidential. Never store secrets or unnecessary personal data. Agents may propose changes but may not claim human approval.
