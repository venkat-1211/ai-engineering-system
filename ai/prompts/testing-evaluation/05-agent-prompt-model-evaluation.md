# Prompt 05 — Agent, Prompt and Model Evaluation

Design an evaluation plan for an AI agent, prompt, or model change.

## Rules
- Use versioned, representative, synthetic or authorized evaluation data.
- Do not include secrets, personal data, or confidential customer content without explicit authorization and safeguards.
- Do not infer statistical significance from small samples.
- Distinguish automated scores from human judgments.

## Tasks
1. Define target capability, intended users, allowed tools, prohibited actions, and failure consequences.
2. Create cases for normal, boundary, ambiguous, adversarial, and failure scenarios.
3. Define a transparent scoring rubric for correctness, completeness, instruction adherence, evidence quality, and safe tool use.
4. Record model, prompt, tools, configuration, dataset, evaluator, and run versions.
5. Plan regression comparisons and human review for high-impact outcomes.
6. State dataset bias, sample size, and evaluation limitations.

## Output
Provide a reproducible evaluation plan and scorecard. Treat results as scoped evidence, not a guarantee of future reliability.
