# Engineering Decision Memory

Record significant choices with ID, title, date, status, owner/approver, context, problem, constraints, alternatives, evaluation criteria, selected option, rationale, consequences, risks, affected components, evidence, and review trigger.

Statuses: `Proposed`, `Accepted`, `Rejected`, `Deprecated`, `Superseded`. Record who authorized transitions and when. A proposal is not accepted.

Describe real alternatives, trade-offs, rejected options, assumptions, reversibility, migration impact, and revisit conditions. Separate evidence from preference. Agents may draft and compare decisions but cannot approve them. If implementation differs from the record, report the divergence.
