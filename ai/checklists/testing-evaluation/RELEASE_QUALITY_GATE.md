# Release Quality Gate Checklist

- [ ] Required tests ran against the intended commit
- [ ] Failures investigated; no hidden or broadly ignored errors
- [ ] Skipped, blocked, and not-run checks explicitly listed
- [ ] Regression suite and critical user journeys verified
- [ ] Security, performance, accessibility, and resilience checks selected by risk
- [ ] Defects triaged and release-blocking issues resolved or formally handled
- [ ] Test data and artifacts contain no exposed secrets or unnecessary personal data
- [ ] Evidence records environment, commands, versions, and commit SHA
- [ ] Residual risks and environment differences documented
- [ ] Exceptions approved by authorized humans and time-bounded
- [ ] Rollback/mitigation and operational handoff considered
