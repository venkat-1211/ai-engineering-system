# Cross-Project Reuse and Isolation

Default: project knowledge is confidential to that project. Enforce access checks before indexing, searching, retrieving, summarizing, embedding, caching, or context inclusion; post-retrieval filtering alone is insufficient.

Prevent leakage through snippets, metadata, embeddings, logs, caches, summaries, prompts, and handoffs. Apply least privilege and tenant identity consistently. Share only sanitized, approved knowledge. Preserve source links only where recipients are authorized. If authorization is uncertain, stop and ask the owner; technical access is not permission.
