# Security Release Gate Checklist

- [ ] Threat model reviewed
- [ ] controls have implementation evidence
- [ ] applicable adversarial tests executed on release candidate
- [ ] exact commit/environment/configuration/scope recorded
- [ ] blocking findings resolved and independently verified
- [ ] accepted risks approved/scoped/unexpired
- [ ] secrets/data isolation/dependencies/tool permissions reviewed
- [ ] monitoring and rollback/disable ready
- [ ] human release authority recorded
