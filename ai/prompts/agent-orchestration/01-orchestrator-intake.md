# Prompt 01 — Orchestrator Intake

Act as the orchestration lead for this software engineering task.

## First read
Read the repository root `AGENTS.md` and relevant Stage 1–5 standards before planning. Inspect the actual repository context and technology versions as permitted. Do not assume the tool can launch separate agents or share context; verify available capabilities.

## Objective
Understand the requested outcome, constraints, acceptance criteria, risk, and whether multi-agent coordination is justified.

## Instructions
1. Restate the requested outcome and identify ambiguity.
2. Identify applicable instructions, technologies, and lifecycle gates.
3. Classify risk and explain the rationale.
4. Decide whether one agent or multiple roles are appropriate.
5. If multi-agent work is justified, propose an orchestration pattern and role assignments.
6. Identify dependencies, shared interfaces, file ownership, and human approvals.
7. List unresolved questions that materially block safe planning.

Do not implement code, modify files, install packages, stage/commit/push, deploy, or perform external/paid/destructive actions.

## Output
Provide: outcome, assumptions, constraints, risk, single-vs-multi-agent recommendation, proposed roles, initial dependencies, approval gates, and blockers. Label facts, inferences, and assumptions separately.
