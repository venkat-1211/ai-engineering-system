# Solution Design Gate Checklist

- [ ] Actual repository, stack, versions, and conventions were inspected.
- [ ] Existing architecture and behavior were considered.
- [ ] Component boundaries and data flow are clear.
- [ ] Database and API changes are defined where applicable.
- [ ] Authentication and authorization enforcement are addressed.
- [ ] Security, privacy, and abuse cases are considered.
- [ ] Failure modes, retries, idempotency, and timeouts are addressed where relevant.
- [ ] Performance and operational impacts are considered.
- [ ] Migration, compatibility, deployment, and rollback implications are known.
- [ ] Material decisions and alternatives are recorded.
- [ ] No high-impact unknown is hidden as an assumption.
