# Agent Handoff Checklist

- [ ] Task ID, sender, receiver, and status are identified.
- [ ] Objective and acceptance criteria are included.
- [ ] Relevant repository instructions and standards are identified.
- [ ] Scope, exclusions, and permissions are clear.
- [ ] Files created or modified are listed accurately.
- [ ] Decisions and rationale are recorded.
- [ ] Commands are reported only if actually executed.
- [ ] Test statuses use the approved vocabulary.
- [ ] `Passed` includes execution evidence.
- [ ] Assumptions, limitations, and blockers are explicit.
- [ ] No secrets or sensitive values are included.
- [ ] Next action and accountable owner are clear.
- [ ] Receiving agent verifies critical context before acting.
