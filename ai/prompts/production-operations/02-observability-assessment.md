# Prompt 02 — Observability Assessment

Read repository instructions and Stage 7 observability standards. Perform a read-only assessment of existing logs, metrics, traces, dashboards and alert configuration using safe, non-secret-bearing evidence.

Assess usefulness, coverage, privacy, retention, cardinality, ownership, alert routing and runbook linkage. Distinguish configuration presence from verified runtime behavior. Do not expose secrets, tokens, personal data or confidential operational details. Do not modify files or systems.

Report findings with file/path or evidence references, severity, impact, confidence, verification status and recommended next action. Do not claim end-to-end telemetry or paging works unless it was actually tested with authorization.
