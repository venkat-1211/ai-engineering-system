# Test Readiness Checklist

- [ ] Current repository instructions and existing test conventions inspected
- [ ] Change scope, dependencies, and affected interfaces identified
- [ ] Observable acceptance criteria agreed or ambiguities recorded
- [ ] Risks and verification depth selected proportionately
- [ ] Test environment, versions, permissions, and data are appropriate
- [ ] Test data is synthetic or authorized and sanitized
- [ ] Required secrets are handled securely and not logged
- [ ] Commands, owners, exit criteria, and evidence locations defined
- [ ] Production and shared-environment protections confirmed
